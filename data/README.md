# Data Directory

This directory holds the small committed demo audio plus documentation about the larger research data tree.

In the committed submission snapshot, most data-bearing contents are intentionally absent because they were private, large, or generated during experimentation.

Expected subdirectories:

- `sample_audio/`: small committed clips for manual demo/prototype checks.
- `raw_audio/`: canonical input audio, split by class folder.
- `metadata/`: source metadata and generated audit tables.
- `processed_audio/`: normalized audio generated by preprocessing.
- `segments/`: VAD/silence-based speech segments.
- `features/`: hand-crafted acoustic feature tables.
- `external/`: source snapshots kept for traceability.

Most contents were ignored by git because they could be large, private, or generated.

For this submission:

- the repository includes small sample audio folders for edge-prototype checks under `sample_audio/`
- the full research data tree is not included here
- expected subdirectories listed above may therefore be absent in the committed snapshot
